## Output Directory Description
 
This folder contains all files generated during the knowledge graph–based analysis workflow 

### Phytochemical_Distribution_Report.csv
Contains comprehensive information on phytochemicals, including their distribution and associated annotations derived from the knowledge graph.<br>

### OUTPUT_INTERSECTION/
Includes all result files related to intersection analyses, obtained through structured querying of the knowledge graph (e.g., shared targets, or relationships between entities).<br>

### Polypharmacology_New/
Contains output files related to polypharmacology analysis, specifically focusing on similarities or mimicking relationships between SHD phytochemicals and approved drugs.
