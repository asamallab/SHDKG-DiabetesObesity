## Description

This folder contains the primary input files used for generating the Sankey plot and interpreting mechanism of action (MoA) relationships derived from the knowledge graph analysis.

---

## Files

### Master_Herb_Drug_Mimicry_Sheet.csv
This is the main input file for Sankey plot construction. It contains integrated relationships between SHDs, their constituent phytochemicals, molecular targets, and corresponding therapeutic drugs.  
The file enables visualization and interpretation of potential drug-mimicking effects and mechanistic pathways mediated by SHD phytochemicals.

### Herb_Drug_Synergy_Summary.csv
This file provides a restructured summary of the master dataset, designed to facilitate understanding of how different phytochemicals from SHDs converge on shared therapeutic drug targets.  
It is particularly useful for analyzing polypharmacological synergy and target overlap patterns across SHDs.
